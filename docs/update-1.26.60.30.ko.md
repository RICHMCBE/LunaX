# LunaX 1.26.60.30 프리뷰 업데이트

2026년 10월 8일 기준 변경 사항입니다. 대상 클라이언트는 Minecraft Bedrock Preview 26.60.30이며 네트워크 프로토콜은 2225입니다. 이번 변경은 개발 중인 프리뷰 지원을 통합한 것으로, stable 브랜치 병합이 전체 기능의 안정성 검증 완료를 의미하지 않습니다.

## 월드와 블록

- 블록 네트워크 ID를 상태 해시 방식으로 전환하고, 타격 효과가 ID의 상위 비트를 덮어쓰는 문제를 수정했습니다.
- 낙엽의 방향·겹치기·드롭과 거품 기둥의 기본 상승·하강 동작을 추가했습니다.
- 양털·콘크리트 반 블록과 계단 96종, 포플러 건축 블록 17종을 추가했습니다.
- 미지원 블록은 원본 상태와 블록 엔티티 데이터를 보존합니다. 공급기 구현 이후 보존 전용 상태는 1,464개입니다. 보존 전용 블록의 설치·파괴·특수 기능은 비활성이고 충돌·차광은 임시 전체 큐브 기준입니다.
- 정규 보존 상태가 LevelDB 로딩 중 다른 상태로 변환되는 문제를 수정했습니다.
- 3D 바이옴의 초과 패딩 개수와 후행 데이터에 대한 로그 두 곳을 제거했습니다. 실제 데이터 손상 예외와 바이옴 로딩 동작은 유지합니다.

## 공급기

공급기는 9칸 보관함, 내용물·이름·잠금 저장, 방향별 설치와 파괴를 지원합니다. 인접 레버·버튼·레드스톤 블록의 전원이 켜지면 4게임 틱 후 임의의 비어 있지 않은 슬롯에서 한 개를 꺼냅니다.

앞에 상자·통·호퍼·셜커 상자·공급기가 있으면 아이템을 전달하고, 보관함이 없으면 아이템을 배출합니다. 대상 보관함이 가득 차면 원본 아이템을 유지합니다. 레드스톤 가루의 신호 전파, 간접 전원, 화로·양조기 등 특수 슬롯으로의 전달은 아직 지원하지 않습니다. 발사기의 투사체·양동이 동작도 포함하지 않습니다.

## 교육용 블록과 연결

강화유리·원소 블록이 포함된 크리에이티브 목록과 일치하도록 접속 시 교육용 기능을 활성화합니다. 별도 로컬 BedrockProtocol에는 해시 ID의 부호 차이로 같은 아이템을 다르게 비교하는 수정이 있습니다. NetherNet 브리지는 1.26.60.30과 프로토콜 2225를 알립니다.

## 검증과 설치 제한

병합 전 구현 검사에서 LunaX PHPUnit 210개, BedrockProtocol PHPUnit 491개 및 각각의 PHPStan 검사가 통과했습니다. 별도 LevelDB 저장·닫기·재열기 검사에서는 보존 전용 1,464개 상태가 일치했습니다. 공급기 창과 실제 전원 작동, 교육용 블록 설치·파괴의 최종 클라이언트 확인은 남아 있습니다.

stable 병합 후 코드 재생성과 PHPUnit 210개(검증 154,738회)는 통과했습니다. PHPStan은 stable에서 유지한 명령어·신호기·스킨 코드의 타입 선언 등 36개 오류로 실패했습니다. 따라서 병합본의 정적 분석 통과를 의미하지 않습니다. 기존 stable의 명령어 오버로드와 신호기 기능, LunaX 버전 1.4.0은 유지했습니다.

현재 Composer의 공개 의존성 고정값은 이전 프리뷰를 가리킵니다. 이 저장소만 내려받아 일반 `composer install`을 실행하는 것으로는 테스트한 프리뷰 환경이 재현되지 않습니다. 별도 로컬 `TeamSelenyx-BedrockProtocol`과 `TeamSelenyx-BedrockData` 변경을 준비하고 `tools/install-preview-dependencies.ps1`을 사용해야 합니다. 두 의존성의 공개 및 버전 고정, 공식 .30 팔레트 재추출, 인벤토리·제작·대표 게임 동작 검증이 완료되기 전에는 정식 지원 완료로 취급하지 않습니다.

세부 근거와 기존 검증 기록은 [프리뷰 개발 기록](bedrock-1.26.60-preview-prep.md)에 있습니다. 기존 PHAR 파일은 이번 소스 변경으로 자동 갱신되지 않습니다.
